Hotel Occupancy Analysis
Analysis of hotel bookings to identify the highest occupancy month. I used the Kaggle dataset (hotel-booking-demand) to practice data analysis with Python, pandas and matplotlib.
Key findings:

August has the highest occupancy with 8,638 arrivals
City hotels consistently outperform resort hotels across all months
The overall cancellation rate is 37%, which is notably high

Tools used: Python, pandas, matplotlib, Jupyter Notebook
